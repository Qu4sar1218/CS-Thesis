
Backend Features (FastAPI + MongoDB)

Core Face Recognition System
- Real-time face detection and recognition using OpenCV and face_recognition library
- Automatic attendance recording when students are recognized
- Face encoding storage and loading from database
- Camera streaming with bounding boxes around detected faces
- Configurable recognition thresholds and processing settings

User Authentication & Security
- JWT-based authentication system
- Role-based access control (Admin, Teacher, Student)
- Password hashing with passlib
- Secure login endpoints supporting email/username authentication

Student Management
- CRUD operations for student records
- Face encoding upload and storage for recognition
- Student registration with course/year information
- Bulk student data management

Teacher Management
- CRUD operations for teacher records
- Auto-generated 6-digit teacher IDs
- Department-based organization
- Teacher authentication and profile management

Class Management
- Create, update, delete classes with schedules and room info
- Student enrollment in classes
- Class roster management
- Teacher-class assignments

Attendance Tracking
- Automatic attendance via face recognition
- Manual check-in/check-out functionality
- Attendance records with timestamps
- Daily attendance tracking with status (present/late/absent)
- Recently recognized student tracking

Event Management
- CRUD operations for school events
- Event details including date, location, price
- Event-based attendance modes

Receipt Verification System
- Student receipt submission for event payments
- Base64 image storage for receipts
- Admin verification workflow (pending/verified/rejected)
- Payment status tracking per student per event

Analytics & Reporting
- Attendance summary statistics
- Student-specific attendance history
- Class-specific attendance analytics
- Date-range filtering for reports

Database Integration
- MongoDB with collections: users, students, teachers, classes, attendance, events, receipts
- Asynchronous database operations
- Data aggregation pipelines for analytics
